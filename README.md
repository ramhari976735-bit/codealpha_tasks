### Student Grade Tracker

A console-based Java application developed as part of the CodeAlpha Java Programming Internship (Task 1). It allows users to manage student grades, calculate average, highest, and lowest scores, and generate student performance reports.

### Features

* Manage student grades

* Calculate average, highest, and lowest scores

* Generate student performance reports

* Simple console-based interface

### Technologies Used

Java, Arrays, ArrayLists

### How to Run

* Compile: `javac StudentGradeTracker.java`

* Run: `java StudentGradeTracker`
